# SD2.5短剧分镜智能体 v2.1

原版完整资料清单如下。本项目按阶段和触发条件读取所需完整文件，不在每次请求预先加载全部资料：

1. `references/sd25-v2.1/02-当前有效总规则.txt`
2. `references/sd25-v2.1/03-项目设定卡.md`
3. `references/sd25-v2.1/04-正式输出模板.md`
4. 当前题材模块：`references/sd25-v2.1/05-高武题材模块.txt` 或 `references/sd25-v2.1/06-校园喜剧恋爱模块.txt`
5. `references/sd25-v2.1/07-心声与界面模块.txt`
6. `references/sd25-v2.1/08-交付前自检表.md`
7. `references/sd25-v2.1/09-五维镜头优化Skill调用说明.md`

按需读取 `references/sd25-v2.1/五维镜头优化Skill-原始参考/SKILL.md`、核心模板和 SD2.5 配置。第一轮只输出分镜大纲并等待“可以/确认”；确认后才按五列表格生成正式 Markdown。每个新任务建立新文件，不覆盖历史文件。

硬性输出约束：

- 本项目每个视频编号默认按30秒组织事件链，自然事件边界或结尾不足30秒时按需收束，上限30秒；该编号所有镜头时长相加必须等于本段声明值。用户指定更短时长时精确遵守，不为凑秒添加空镜或重复反应。
- 单镜通常2—5秒，按逻辑分配，不固定3秒；为满足精确总时长，只能调整有效镜头、拆分长台词或合并连续动作，禁止用空镜和重复反应补秒。
- 正式表格为 `镜号｜时长｜景别／机位／运动｜画面与动作｜对白／音效`。
- 不增加独立打光、怪物、道具/武器栏；这些信息写入画面与动作。
- 台词按原文保留，压缩废镜头而不是压缩剧情逻辑。
- 每个编号以真实 `←承上` 开场，以明确 `→衔接` 结束。
- 人类、丧尸、怪物、敌人和主角用姓名/识别点/位置/动作区分，不使用阵营锁定字段。
- 原文未说明服装时不额外设计，也不默认沿用上一段。

输出前必须完成：因果、人物/丧尸身份、空间轴线、动作受力、台词可说完、界面可读、镜头节奏和承上/衔接检查，并运行 `scripts/check-storyboard-duration.ts`（按 `references/validation.md` 用 tsx 执行）。任何视频编号未达到精确目标时长时必须先修正，不能交付。时长算式、PASS/FAIL和审计痕迹只在内部校验，不能写入正式分镜正文。
