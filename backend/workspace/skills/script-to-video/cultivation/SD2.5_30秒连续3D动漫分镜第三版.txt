# Seedance 2.5 连续3D动漫交互式分镜

将原文转化为人物真正行动、镜头真正进入三维空间、前后剧情能够衔接的视频提示词。默认采用3D玄幻国漫表现，每次输出一个30秒片段，每句台词与角色声音合并为一行“【配音指令】：……”，片段完成后附人物声音统计；适配其他题材时保留连续3D表演，按原文调整视觉语言。

用户当前明确要求优先于本 Skill 的默认值。用户仅要求学习、点评或修改模板时，完成该请求，不擅自开始分镜。用户明确要求整场一次输出、改变时长或改换风格时，按其要求执行。

## 1. 原文保真与信息取舍

- 保留核心事件、人物关系、因果、重要选择、关键台词、道具、伏笔、反转和结果。允许补足必要的表演与摄影细节，不擅自新增重大事件或世界设定。
- 关键台词保留原话、原说话人、原先后顺序。心理活动不擅自改成口头对白；原有 OS 保持为内心声音。
- 当前片段只揭示原文进行到此处的信息。镜头、特效、人物表情和片段标题也不提前泄露后文答案。
- A类信息：影响剧情与后续理解的事件、证据、选择、台词和结果，必须呈现。
- B类信息：情绪、心理与氛围，优先转成动作、呼吸、眼神、距离、道具反应、声音和光影；不可用新增台词替代。
- C类信息：重复解释、寒暄、无推进的环境或行走，可并入其他镜头或压缩。后来有作用的内容应提升为A类。
- 镜头语言服从题材：现实题材不添加剑气、灵压或法阵；玄幻题材的能力、伤害与结果也必须符合原文。
- 铺垫、沉默、对话、过渡和余波都可以成段，但须有信息、关系、情绪或空间推进。不强迫每段出现高潮、反转或狠话钩子。

## 2. 先规划全文，再逐段交付

首次获得原文时，通读用户提供的全部内容，识别人名、场次、信息揭示顺序和剧情单元，先规划后续拆分，再写当前片段。不要把规划过程或完整拆解表放入正式分镜。

按剧情密度、动作过程、台词时长和转折点拆分，不按字数或自然段平均切割。一个30秒片段承担清楚的小剧情任务；长原文通常需要多个30秒片段，不能为了在一个片段里写完而删改关键内容。

交互规则：

| 用户输入 | 执行方式 |
| --- | --- |
| 首次提供原文 | 默认只输出分镜1；已有连续编号则接续编号。 |
| 确认、继续、下一个、可以 | 确认当前版本，继承尾部状态，只输出下一段。 |
| 修改当前段 | 输出当前段的完整修订版，编号不变，先不推进下一段。 |
| 重做第X段 | 修订指定段；重新检查已受影响的后续内容，不沿用过期衔接。 |
| 后面都保持此风格 | 将要求用于后续；是否重写当前段以用户要求为准。 |
| 提供新场次 | 按新原文推进；原文场号如“2-1”与视频分镜编号分别维护。 |

正式输出不附“是否继续”“等待确认”等提示。用片段末尾的动作、视线、对话、道具、结果或情绪自然接续，不用每段强制悬念。

## 3. 30秒时间预算

- 默认每段总时长准确为30秒。用【起始s-结束s】划分时间轴，从0s连续累计到30s，无重叠、空档或中途归零。需要时可用0.5秒精度。
- 镜头数量由内容决定。一般可从8—14个镜头规划，安静段可更少；这不是配额，也没有沿用旧版“最多6镜/8镜”的硬上限。镜头过密、动作来不及或对白说不完时拆到下一片段。
- 常见镜头为1—4秒；完整情绪表演、长对白、组剑或化形可占4—7秒。1秒镜头只容纳一个易辨认的短动作或简短回应。
- 先按台词反推时间，再安排动作与摄影。正常对白参考每秒3—4个中文字，虚弱、耳语或带明显停顿参考2—3字，激动快语或自然较快的OS参考4—5字。数值是规划参考，需为呼吸、停顿和反应留量。每条配音指令中的语速、停顿和气息必须与这个区间实际时长一致。
- 一个时间区间原则上只有一个说话人物。长台词按语义、停顿和情绪拆到相邻镜头；不能靠不自然的高速口播塞入30秒。
- 关键台词过长时保留原话，增加镜头或留给下一段；不为了迎合镜头长度删掉关键信息。
- 说话与抬手、观察、走近等动作可以合理同步。OS可以覆盖相关行动，但不能因此提前发生后面的反转、反应或决定。
- 不把30秒机械分为等长的“开场/冲突/高潮/钩子”。按本段功能给重要动作与反应足够时间。

## 4. 连续3D动态：避免PPT观感

“3D”必须落实为画面中的连续运动，不能仅在开头添加“3D、电影级”等标签。

每个镜头至少明确：主体正在完成的动作、可见表演、空间层次、视觉焦点；运镜与环境动态按该镜的叙事需要补充。

1. **身体过程**：写清支撑、重心转移、发力、受力和收势。坐起要有撑地与躯干抬起，挥剑要有脚步、腰肩带动与腕部收势；不要只写前后两个姿势。
2. **次级运动**：衣袖、裙摆、头发与身体运动存在延迟，随惯性摆动后落定；不是与人物一起作为整张图片平移。
3. **接触反馈**：脚掌落地带动碎土，手掌撑地受力，身体撞柱使头发与衣料继续运动，剑气照亮附近表面；强度符合剧情，不额外制造大爆炸。
4. **空间视差**：移动摄影机时写出路径、前景遮挡和纵深变化，例如贴柱横移、过肩前移、贴地追踪。近景物体移动通常比远景明显。
5. **环境连续**：云层、电弧、尘土、风与光影具有体积和持续变化。只使用当前环境允许的动态；劫云散开后不凭空恢复雷劫。
6. **安静也有表演**：固定机位可以保留，人物仍有视线、呼吸、停顿和细小姿态变化。不为了“动态”强迫每镜旋转摄影机或让人物乱动。

全局提示明确排除：静态立绘推拉、图片平移缩放、纸片人、漫画分格、PPT转场、无故定格。角色的真实动作与空间变化是主要正向描述，负向词只作补充。

这份 Skill 产出视频提示词，不代表已经制作了3D模型或生成了视频，也不保证生成结果一定满足提示词。

## 5. 让镜头服务戏剧

首次进行玄幻修仙分镜或用户要求丰富镜头时，参考本文件末尾的“附录：3D玄幻修仙的摄影与表演应用”。同一对话中不必每段重复阅读。

| 镜头方式 | 合理用途与限制 |
| --- | --- |
| 建立镜头、双人/多人中景 | 交代谁在何处、朝向、距离、入口和行动路线；位置已清楚时不必每段重来。 |
| 正反打、过肩 | 对话、试探、追问与反应。写明从谁背后拍、谁的后脑/肩背在哪侧虚化、焦点落在谁脸上。 |
| 主观视线与反应切镜 | 先给视线或发现，再给其看到的道具、天空或身体细节，再接反应；不提前暴露信息。 |
| 荷兰角 | 用在局势骤变、失衡、认知受冲击等节点。通常小幅倾斜即可；不要求每段都有，也不把从容角色全程拍得慌乱。 |
| 低机位仰拍、高位俯拍 | 强调力量与体量，或呈现受伤、弱小与空间关系；根据实际人物处境使用。 |
| 横移、升降、小弧移 | 建立纵深、露出遮挡、跟随动作或展开法宝；说明路径，不随意360°环绕或越轴。 |
| 短促推近、快速摇摄 | 强化发现或追随突发行动；写明触发点、方向、落点，不能只写“镜头乱晃”。 |
| 贴地追踪、侧向跟拍、飞行跟拍 | 体现剑气、击退、追逐与飞行路线；让地形与遮挡提供速度感，同时保留因果。 |

正反打是切换相对机位，不是要求摄影机机械旋转180°。通常保持在人物关系轴线同侧，保证视线、左右关系与行动方向可辨；若必须跨轴，先用连续可见的摄影机运动或新的建立镜头重新交代空间。

多人戏在关键站位变化时用同框镜头交代全局。主对话推进时穿插有剧情作用的旁观者反应，或在画面边缘保留虚化身影；不为满足固定次数强行切镜。

每镜有一个主景别、一个主摄影运动、一个视觉焦点和一个主要动作意图。机位高低、画面倾角与过肩构图可与该运动结合，但不把“推近、拉远、环绕、俯冲、快切”同时塞进一个镜头。

默认战斗保持正常或稍快速度，动作一气呵成，不使用慢动作、定格慢放与无理由停顿。充分表现准备、发招、接触、结果；不必把每个细小动作都切一镜。用户另有明确要求时再调整。

## 6. 状态与连续性

只在当前可用对话中维护工作状态，不声称已永久记忆。记录足以支持后续的内容，不向正式分镜附内部档案或推理过程。

- 角色：外貌、衣发、已知身份、性别、年龄或声音年龄感、固定音色或绑定的声音素材、语言口音、当前语气与气息、情绪、伤势、疲惫、持物与已知信息。
- 空间：人物世界位置及当前画面位置、前中远景、朝向、间距、摄影机所在轴线侧、入口出口。
- 道具：持有人、落点、完损、收纳与取出的动作；剑已入袖后不能下一镜凭空握在手中。
- 场景：时间、天气、光线、战斗痕迹、未散的尘土与法术余波。
- 叙事：原文已用到哪里、已揭示/未揭示信息、当前片段版本、编号、尾部动作与下一段承接点。

横向位置、纵深与朝向直接写入“运镜”行。发生位移时写明起点、路径与终点；不能将摄影机反打造成的构图变化误写成人物实际瞬移。

新片段承接最近确认版的末尾状态，镜头可换景别，但时间、人物动作和位置必须能接上。修改前段后重查受影响内容。上下文缺失且无法可靠恢复时，索取最少的前段资料，不编造尾帧。

## 7. 用一行配音指令合并角色声音与台词

每次出现口头对白、OS、画外对白或“啊”“哈”“嗯”等短回应，均使用下面的固定格式。不再分成独立的台词行和声音提示行。

```text
【配音指令】：角色名｜性别｜年龄或声音年龄感｜固定音色或真实素材绑定｜本句语气/情绪｜音量｜语速｜发声类型（段序/总段数）｜语言｜「原文台词」
```

使用全角分隔符“｜”，字段顺序固定为十项，最后一项用“「」”包住实际台词。用户提供的村长、年龄与台词等示例仅作格式示范，不自动成为当前剧情的人物或事件。

| 字段 | 填写规则 |
| --- | --- |
| 角色名 | 使用当前实际说话人姓名或原文身份，声音与台词归属一致。 |
| 性别 | 沿用原文或用户设定；未明确时写“未明”，不任意改动。 |
| 年龄或声音年龄感 | 已知时可写“65岁左右”；未知真实年龄时可写“青年年龄感”“少女年龄感”或“年龄未明”，不把配音年龄感当作角色真实年龄。 |
| 固定音色或真实素材绑定 | 如“苍老沙哑老年男声”“清朗青年男声”；已上传声音时明确沿用对应角色绑定音色或实际音频编号。 |
| 本句语气/情绪 | 如“震惊颤抖”“平淡干脆”“虚弱迷茫”；必要的气息、重音、停顿与尾音可简写在同一字段内。 |
| 音量 | 如“轻声音量”“中等音量”“中等偏高音量”，与当前表演一致。 |
| 语速 | 如“缓慢语速”“正常语速”“正常偏快语速”，必须与时间区间的容量一致。 |
| 发声类型与段序 | 使用“对白（1/1）”“对白（1/2）”“OS（1/1）”或“画外对白（1/1）”等，标明类型与连续发言的拆段顺序。 |
| 语言 | 默认“中文普通话”；用户指定其他语言或口音时按其要求，不能擅自翻译原台词或改换口音。 |
| 原文台词 | 原话保真，只朗读此项中的内容，不读前面的字段。 |

执行规则：

- **逐条完整**：同一角色重复说话时，每条都写完整十项，不使用“同上”省略，也不能用全局声音设定代替本句指令。
- **声音连续**：首次建立角色的音色、音区、质感与口音档案；后续只改变本句表演，不随情绪更换人物声音。
- **素材真实**：已经上传声音时沿用对应角色的主体绑定音色，不另造声线；没有素材时建立稳定音色描述，不虚构音频编号或已上传的事实。
- **分段标记**：一条完整发言不拆分时用“对白（1/1）”；同一条连续发言拆成两段时依次为“对白（1/2）”“对白（2/2）”，OS同理。原文中彼此独立的回答重新从“1/1”开始。括号表示发言拆段，不是分镜编号、人物数量或全片台词编号。
- **OS与口型**：OS沿用本人音色，在发声类型字段标注OS，画面不做口型；不因OS自动换声线、变耳语或追加夸张混响。普通对白保持口型与动作同步。
- **表演可执行**：情绪、音量、语速、气息和停顿要互相协调。虚弱耳语不能配不自然的高速长句，时间不足就拆分。
- **非朗读信息**：标签和前九项均为生成指令，不朗读、不作为字幕。声效行继续负责环境、动作及必要的非语言声音。
- **无台词**：该行写“【配音指令】：无台词”，不填虚构角色与声音。人物叹息、呼吸等非语言声音可在声效行标明归属并沿用其音色。

格式示例：

```text
【配音指令】：余家村村长｜男｜65岁左右｜苍老沙哑老年男声｜震惊颤抖｜中等偏高音量｜正常偏快语速｜对白（1/2）｜中文普通话｜「神……神仙手段！平地变出大宅院，」

【配音指令】：方闲｜男｜青年年龄感｜清朗青年男声，音区中低、略带松弛感｜平淡干脆，句尾收住｜中等偏轻音量｜正常语速｜对白（1/1）｜中文普通话｜「劈碎了。」

【配音指令】：夏叶｜女｜少女年龄感｜清亮少女声，气息略虚弱｜短促惊疑，尾音上扬｜中等音量｜正常语速｜对白（1/1）｜中文普通话｜「哈？」

【配音指令】：夏叶｜女｜少女年龄感｜清亮少女声，保持本人音色｜虚弱迷茫，气息不足、尾音渐弱｜轻声音量｜缓慢语速｜OS（1/1）｜中文普通话｜「骗人……」
```

村长示例展示一条发言的第1段；正式使用时，第2段应承接用户提供的原文后半句，不自行补造。人物音色以用户素材、原文与已经确认的声音档案为准。

例如，用户确实已经上传并绑定方闲声音时：

```text
【配音指令】：方闲｜男｜青年年龄感｜严格沿用方闲主体绑定的上传声音，保持原音色与口音｜平淡干脆，句尾收住｜中等偏轻音量｜正常语速｜对白（1/1）｜中文普通话｜「劈碎了。」
```

## 8. 每段完成后统计人物声音

每次交付分镜，包括修订版，都在分镜正文之后附“人物声音统计（不计入视频时长）”。统计以当前输出版本为准，不把已删除台词或其他片段的声音算进来。该统计是制作备注，不作为视频字幕、旁白或角色台词。

- 按角色汇总固定音色或实际素材绑定、本段发声表现、口头对白条数和OS条数。同一角色的对白与OS保持同一声音身份，不算成两个人。
- 条数按正文中包含角色与台词的有效“【配音指令】”行计数，包括“啊”“哈”“嗯”等短回应；一条指令内有多个标点仍计一条，同一发言拆为两个镜头的两条指令则分别计数。
- “【配音指令】：无台词”不计数；全局声音设定、声效说明与统计表本身也不计为台词。根据指令中的发声类型区分对白与OS；画外对白计入口头对白，必要时另注其类型。
- 只列本段需要配音的角色，不把仅出现在画面中但未发声的人物计入。若另有可辨认的角色叹息、哭声等独立非语言配音，注明人物与类型，不混算进对白或OS条数。
- 表内音色、素材绑定与本段逐条配音指令一致；不因为统计重新设计角色声音。未上传音频时不虚构音频文件名或素材编号。
- 表后给出本段配音角色总数、口头对白总条数与OS总条数。不把镜头区间长度当作实际说话时长，也不编造音频长度。
- 没有人物台词时也保留统计说明，写明“本段无口头对白或OS”；如有独立非语言配音，另按实际情况列出。
- 片尾统计不能代替逐条配音指令，也不能代替连续性记录。

## 9. 正式输出格式

默认交付下面形式的一个片段及片尾人物声音统计，不加分析、创作说明、剧情梗概、完整拆分表、连续性检查或等待确认提示。用户另问原理、资料或修改理由时可单独说明。

```text

动作：……
【配音指令】：无台词
声效：……
情绪提示：……

| 人物 | 固定音色或素材绑定 | 本段发声表现 | 口头对白条数 | OS条数 |
```

有主体/声音素材时才引用其编号或绑定；没有上传素材就维持当前角色设定与稳定音色，不虚构参考图、音频或“已经上传”的事实。全局声音设定不能替代任意一条配音指令；同一角色反复说话时，每条仍写完整字段，不使用“同上”省略。

## 10. 交付前检查

在内部修正后再输出：

1. 原文事实、关键台词归属、事件顺序与揭示节点准确。
2. 时间区间首尾相接且合计30秒，台词、停顿与动作实际装得下。
3. 人物在连续表演，场景与摄影具有空间变化，不是静图加推拉。
4. 镜头选择有剧情理由；正反打不混淆轴线，荷兰角不滥用，摄影运动不互相冲突。
5. 站位、伤势、衣发、道具、天气和信息状态继承最近确认版。
6. 法术或战斗过程有方向、有受力、有结果；未新增无关设定或提前揭露答案。
7. 末尾留有可继续的状态，不无故定格，不强造钩子。
8. 每句台词都有十项齐全且顺序正确的配音指令，短回应与OS没有漏标；角色、性别、年龄感、音色/素材绑定与语言正确，语气、语速、音量和气息符合本句及其时长。
9. 五行格式完整，配音拆段编号与连续发言对应，分镜编号连续；正式结果包含当前分镜与其片尾人物声音统计。
10. 人物声音统计与本版正文逐条对应，角色总数、对白条数和OS条数准确；统计内容不进入30秒视频时间轴。

# 附录：3D玄幻修仙的摄影与表演应用

用于挑选具体镜头、处理轴线或修正PPT观感。以下角度和时长是创作参考，不是模型参数保证，也不要求每段全部使用。

## 1. 先写“为什么切”，再写“怎么拍”

识别本镜的主要任务：交代位置、观察、回应、揭示、失衡、反击、结果或转场。只选择能够完成该任务的主摄影运动。

丰富镜头来自视角、景别、层次、表演和节奏的配合，不是镜头名称越多越好。角色面临危险但仍掌控局势时，可以让环境倾斜动荡，而他的回应镜头保持水平稳定。

## 2. 对话与反应：正反打

先建立A在左、B在右的基本空间，摄影机保持在两人连线同一侧：

- 拍A：从B肩后拍，B的后脑/肩背在右前景虚化，A位于左中景清晰。
- 拍B：从A肩后反打，A的后脑/肩背在左前景虚化，B位于右中景清晰。
- 让两人的视线分别朝向对方，不让二人都看同一画外方向。
- 前景保留真实遮挡与呼吸引起的细微变化，不用一张模糊正脸当背景贴片。
- 身份、距离或高低关系有变化时，侧面双人镜头可以重新说明。

这是一组相对机位，不是“把摄影机直接转180°”。无理由越过关系轴线会让左右和视线混乱。需要跨轴时，让观众看见摄影机连续走过轴线，或用清楚的建立镜头重新定向。

不要机械地一句台词必接一张静脸。可用回应前的停顿、撑地靠近、收手、眼神转移或道具动作，让正反打中的人物持续表演。

多人戏中，谁的反应改变观众理解就切谁；其他人物可保留为虚化前景、侧影或背景站位。不以“每隔几镜必须切一次”代替戏剧判断。

## 3. 局势突变：荷兰角

荷兰角是画面绕光轴发生倾斜，区别于普通的向上/向下摇摄。

- 小幅约5°—15°可用于突如其来的闯入、无法理解的回答或环境失衡。
- 更强倾斜只在明确需要强烈失序感时使用，避免影响动作方向的辨认。
- 写“门柱与地平线倾斜”，同时说明倾斜方向；人物依然按重力站立，不是让整个场景倒塌。
- 突变结束、人物重新控制局势时，可以切回水平构图形成落差。
- 一段不需要失衡就可以完全不用。不要全片持续倾斜，也不要用旋转镜头掩盖不清楚的站位。

应用示例：大汉突然闯入时低机位微倾，表现打断；随后切回水平近景拍方闲从容观察。少女听到离谱答案时短暂倾斜反应镜，回答者仍保持稳定。

## 4. 力量、弱势与尺度

| 任务 | 镜头选择 | 应写清的画面证据 |
| --- | --- | --- |
| 弱小生灵承受威压 | 贴地近景或高位俯拍 | 身体/草叶受力、地面距离、上方遮挡和风压。 |
| 从容者准备出手 | 稳定低机位中近景 | 脚下支撑、肩臂准备、脸部控制，环境运动与人物稳定形成关系。 |
| 一剑破开巨大劫云 | 人物与云同框的仰拍全景 | 人物占画面小部分，剑气路径、命中处和云体分离有因果。 |
| 强者说平淡的话 | 水平反打或轻微仰拍 | 台词节奏与稳定姿态；不必新增威压特效。 |

不能靠一连串没有参照物的特写表现规模。至少用一个镜头交代人物、目标与环境的相对体量。

## 5. 法宝、组剑与化形

组剑写清“来自哪里—如何运动—在哪里成形—最终由谁握持”。碎片在真实空间中旋转校准并聚合，保留原文规定的裂痕、缺损与颜色。

可用单侧约15°—45°的小弧移显示碎片厚度、遮挡与纵深；这不是要求每次组剑都环绕。用2—4秒或更长承载可辨认的聚合过程，不把完整过程硬塞进一秒。

化形保持原地空间一致。光芒包住原形，轮廓连续改变，显形后的衣裙与头发自然落下；不能突然切到不相干位置的人物照片。白光可以遮挡变化，但不能替代变身前后的地点、体量与状态衔接。

法术亮度应影响附近地面、衣物和人物轮廓，不仅是贴在画面表面的发光线。效果强度以原文为限。

## 6. 战斗与飞行

先让观众知道谁打谁、从哪里打向哪里，再选择追踪方式。

- 准备：中景或手部近景，脚掌支撑、剑指并拢或握柄蓄力。
- 发招：保留腰肩与手臂的连续发力，只有主角出招时不添加对手的新攻击。
- 追踪：沿剑气方向贴地前冲，利用近处地形快速后退表现速度；不要把主角整个人当贴图在画面里滑动。
- 接触：用侧向跟拍呈现击退路线，撞击后头发、衣物继续运动，地面产生相称反馈。
- 结果：给落点、伤势、法术散去与站位，不用仅有强光的镜头替代命中结果。
- 飞行：起身有蹬地或原文规定的起飞方式；持续飞行时衣发受风、近景地形掠过、远景变化较慢。速度和摄影路径都保持可辨。

默认正常或稍快速度。快速摇摄应有明确起点、方向和落点；不同时加入环绕、俯冲、反向拉远等冲突运动。

## 7. 安静镜头也能是完整3D表演

避免写：“少女惊讶，镜头推近。”

改为：“少女右中景坐在焦土上，双手撑地将身体向左侧挪近，肩膀前倾，长发滑向胸前；从男子肩后反打，男子肩背在左前景虚化，摄影机随她靠近小幅后退，保持脸部清晰。”

避免写：“女子被击飞，特效震撼。”

改为：“女子从右中景被击退至右后方门柱，摄影机沿受力方向横向跟拍；后背撞柱时身体折停，长发与裙摆继续甩动，再沿柱滑坐，柱脚浮尘被震起。”

固定机位中，呼吸、目光、握手、迟疑与细微姿态也能形成连续表演。不要为避免静态而添加原文没有的走动或情绪爆发。

## 8. 转场与时长

- 换场写清触发动作：跨门、转身、视线引导、声音先入等。门柱擦过镜头可以自然展开室外空间。
- 角色抬头后再切其所见天空，回来时保留原来的站位和光线。
- 一次剪切发生在动作连续点，不要求每个片段末尾定格或黑屏。
- 30字的耳语按每秒2—3字估算，需要约10—15秒，尚未计入停顿。无法容纳就拆分，不能以“语速加快”消除时间预算。
- 3D动态应由连续动作、遮挡、视差和反馈共同表现。提示词只能提出这些要求，不能把文字中的“3D”当作已经生成三维资产的证明。
