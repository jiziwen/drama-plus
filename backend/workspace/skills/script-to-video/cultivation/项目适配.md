# 修仙分镜项目适配

[修仙技能原稿](SD2.5_30秒连续3D动漫分镜第三版.txt)全文随生成请求载入。运镜、连续三维表演、空间与道具状态、逐条配音和附录中的创作要求按原稿执行。以下约定补充工作台的交互与数据交付方式。

## 大纲、时长与续接

- 本集已确认的剧本和分段大纲对应原稿的全文规划。沿用确认的情节顺序、关键状态与素材选择。原稿交互表描述人工逐段对话，工作台调用时以本次请求指定的片段范围为准。按当前时间表逐段对应 `targetCardIds`。重排后根据新时间表和本次批次说明确定待交片段。
- 优先按确认大纲的 `duration` 执行。应用允许尾段按剧情收束。人声需要跨段重排时先提交整集时长方案，保证台词完整，逐镜时长连续累加至各段确认的时长。续写从应用提供的上一段实际末镜接起。
- 默认使用连续三维玄幻国漫表现。按实际题材和用户确定的风格保留连续动作、空间层次和接触反馈，已有统一风格与绑定素材是当前项目的输入。

## 工作台字段与正式提示词

- 在整集制作规格中填写画面、声音、镜头节奏和人物状态。每段的场景、人物、关键道具状态与声音设定放进相关既有结构字段。开场和结尾按实际站位、动作和声画状态承接。
- 每镜 `duration` 填时长，`camera` 填原稿的「运镜」，`action` 先写「动作」正文，再换一行写 `情绪提示：` 和实际表演。`dialogue` 依次放完整配音记录及独立的 `音效：` 行，由程序渲染为原稿的配音指令和声效字段。
- 每句使用 `角色名【性别｜年龄或声音年龄感｜固定音色或真实素材绑定｜语气/情绪｜音量｜语速｜发声类型（段序/总段数）｜语言】：「原文台词」`。心声在角色名后标记 `(OS)`，画外对白标记 `（画外音）`。发声类型分别填 `对白（1/1）`、`OS（1/1）` 或 `画外对白（1/1）`，按实际拆段调整编号。每条配音独占一行，已绑定的声音以真实素材为准，台词及说话人照原文。
- 无台词镜头的 `dialogue` 首行写 `无台词`，下一行如实写 `音效：`。音效包含这一镜的环境、动作及非语言声音。逐镜的 `visualAssetIds` 和 `speakerAssetIds` 使用本次清单中的真实 ID。
- 程序使用这些字段生成每段的连续时间区间、运镜、动作、十项配音指令、声效与情绪提示。逐条配音记录也是人物声音统计的唯一来源。匹配本段正文的统计作为交付文稿的制作备注，视频提交用逐镜正文。
