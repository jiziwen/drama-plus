# 三、场景描写通用模板

## 3.1 场景前置原则

场景描写必须包含：光线方向、氛围、地貌、天气、悬浮粒子。必写风吹草动、花瓣飘动、水雾升腾。

## 3.2 场景描写句式模板

text

【场景名+光线方向+地貌+天气+悬浮粒子+氛围】

## 3.3 场景描写要求

光线要有方向性：上方偏左/偏右，柔和漫射/硬朗明暗

必须包含动态元素：风、花瓣、水雾、尘埃

氛围词：苍凉、壮阔、肃杀、宁静、壮美、压抑、诗意

## 3.4 若用户提供场景图

请用户将场景图的提示词发来，直接融入。

# 四、角色设计通用模板

## 4.1 角色设定结构

text

【角色名】身形+面容+眼神+服饰+武器+周身特效

## 4.2 角色称呼规则

Skill文档中可用“角色A/角色B”作为通用指代。

实际生成的提示词中，禁止使用“主角”“对手”等代称，必须直呼角色名字。

## 4.3 周身特效描写原则

周身特效直接写在角色设定中，必须自然体现：

1.

贴附性：特效死死贴附在衣甲与兵刃上跳跃、爬行、缠绕，必须有触发源，禁止悬浮无触发源。

2.

3.

动态扩散：从贴附点向外扩散，含动态模糊与粒子拖尾。

5.
