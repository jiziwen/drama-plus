# SD2.5短剧分镜智能体｜可直接移交版 v2.1

这是一套面向 SD2.5 的短剧分镜工作包。它保留上一版的原始条例，并把本对话已经确认的新版要求、镜头节奏和五维镜头 Skill 接入为当前有效规则。

## 最快使用方法

1. 将整个文件夹交给新的 AI 对话，不要只上传单个提示词。
2. 复制并发送 `01-一键启动提示词.txt`。
3. 填写 `03-项目设定卡.md`；不同作品重新填写，不能跨剧继承人物和风格。
4. 粘贴一章小说或一段剧情。AI 第一轮只能给“分镜大纲”，不能直接生成正式分镜。
5. 回复“可以”或“确认”后，AI 才生成对应的 Markdown 分镜。
6. 正式分镜完成后必须逐个编号累加镜头时长，并运行 `scripts/check_storyboard_duration.py`；默认每个编号必须恰好30秒，校验失败不得交付。
7. 每次新分镜另建新的 `.md` 文件；修改旧视频编号时只输出修改后的新文件，不覆盖历史文件。

## 文件说明

- `01-一键启动提示词.txt`：交给新 AI 的第一条消息。
- `02-当前有效总规则.txt`：当前真正执行的主规则；冲突时优先级高于历史条例。
- `03-项目设定卡.md`：每部新剧单独填写。
- `04-正式输出模板.md`：新版五列表格、承上/衔接和场景文件格式。
- `05-高武题材模块.txt`：战斗画面、能力因果、规模递进和环境反馈。
- `06-校园喜剧恋爱模块.txt`：恋爱反应、心声反差和喜剧节拍。
- `07-心声与界面模块.txt`：心声、系统、新闻和清晰文字。
- `08-交付前自检表.md`：交付前逻辑、节奏和格式审计。
- `09-五维镜头优化Skill调用说明.md`：如何调用五维导演规划和 SD2.5 封装规则。
- `五维镜头优化Skill-原始参考/`：用户提供的五维 Skill 原件，原样保留，按需读取。
- `历史版本-v1.0/`：上一版完整快照，仅用于追溯，不作为当前执行规则。
- `原始条例-不得修改/`：历史条例原件，原样保留，不得改写或覆盖。

## 执行优先级

1. 本次用户最新明确要求和原文不可更改项。
2. `03-项目设定卡.md` 的当前项目设置。
3. `02-当前有效总规则.txt`。
4. 当前启用的题材模块与 `09-五维镜头优化Skill调用说明.md`。
5. `原始条例-不得修改/` 中的历史条例（只作追溯；与当前规则冲突时不执行旧条款）。
6. 示例文件。

## 新版关键默认值

- 默认每个视频编号固定30秒，逐镜相加必须恰好等于30秒；用户另有时长要求时，改为精确等于用户指定时长。
- 镜头时长按逻辑灵活分配，通常 2–5 秒，不固定 3 秒；长台词、完整动作或界面阅读可适当延长。
- 一段通常 8–10 个镜头，但不为凑数量增加废镜头。
- 正式表格只保留五栏：`镜号｜时长｜景别／机位／运动｜画面与动作｜对白／音效`。
- 不设置独立打光栏、怪物栏、道具／武器栏；相关信息直接写入画面与动作。用户单独要求时再提供资产参考。
- 台词按原文保留，优先压缩空镜和重复动作，不擅自删关键对白。
- 每个编号开头写真实承上末帧，结尾写明确衔接；不重播上一编号的首镜。
- 29秒、31秒或只写“约30秒”都视为时长校验失败；不得用空镜、重复反应或无效走路补秒。
