# 交付前自检表 v2.1

## 规划与文件

- [ ] 是否先给出视频编号、核心事件、人物、场景复用、台词策略和拆分理由？
- [ ] 是否等用户“可以/确认”后才生成正式分镜？
- [ ] 新分镜是否写入新 Markdown 文件，没有覆盖旧文件？
- [ ] 是否按五维 Skill 按需完成节拍、摄影、连续性和生成风险判断？

## 时长与节奏

- [ ] 是否逐个编号计算“时长”列，默认每个编号的算术和恰好等于30秒，而不是29秒、31秒或“约30秒”？
- [ ] 用户指定其他时长时，是否每个编号精确等于该目标？
- [ ] 是否运行 `scripts/check_storyboard_duration.py`，且全部编号显示 PASS？
- [ ] 是否仅内部运行时长校验，正式分镜正文没有出现算式、PASS/FAIL或“时长硬校验”标注？
- [ ] 镜头是否按逻辑灵活分配在2–5秒左右，没有机械固定3秒？
- [ ] 是否大致8–10镜且每镜有功能，而不是为凑数量堆镜头？
- [ ] 是否删除空镜、发呆、无效走路、重复反应和重复解释？
- [ ] 爆点前是否保留准备，爆点后是否保留结果/钩子？

## 台词与声音

- [ ] 原文台词是否逐句保留，未经许可没有改写或删掉关键暧昧/笑点？
- [ ] 长台词是否在自然停顿处拆分，正常语速能说完？
- [ ] 每个主要说话人和情绪是否明确，声音是否避免统一AI腔？
- [ ] 心声是否由角色本人声音念出，现实人物是否仍有动作？

## 人物、丧尸与连续性

- [ ] 人物栏是否只列清晰出镜、说话或关键行动人物？
- [ ] 人类、丧尸、怪物和敌人是否写明身份、外观识别点、站位和行动目标？
- [ ] 是否没有使用“阵营锁定”字段，却通过身份、站位和动作避免串角？
- [ ] 是否没有人物凭空消失、换位、复活或无说明变异？
- [ ] 伤势、血迹、疲劳、手中物件和动作惯性是否逐镜继承？
- [ ] 原文未说明的服装是否没有被擅自设计，也没有默认沿用上一段？

## 摄影与动作

- [ ] 每镜是否写了景别、机位/角度、运镜动机和主体位置？
- [ ] 运镜是否服务追踪、揭示、冲击、反应或转场，是否删掉无意义慢推？
- [ ] 动作是否包含准备、触发、运动、接触/受力、结果和环境反馈？
- [ ] 战斗是否真的展示招式、碰撞、破防、移动和结果，而不是长对话？
- [ ] 上一镜末帧与下一镜首帧的方向、位置、速度、视线和声音是否连续？

## 界面与输出格式

- [ ] 系统、手机、新闻和职业面板是否正面、清晰、大字号、高对比、无乱码？
- [ ] 正式表格是否严格五栏：镜号、时长、景别/机位/运动、画面与动作、对白/音效？
- [ ] 是否没有独立打光设计栏、怪物栏、道具/武器栏？
- [ ] 道具、武器、丧尸和生物是否已在画面与动作中标明持有者、状态和结果？
- [ ] 每个编号是否有真实`←承上`和明确`→衔接`，且没有重播上一段？
- [ ] 末镜是否落在爆点、危险、决定、关系变化或下一段信息钩子？
