# 版本说明

版本：`2.1｜固定30秒硬校验修正版`

## 本版保留

- 上一版完整文件和“原始条例-不得修改”原件；原件未改写。
- 高武、校园恋爱、心声与界面题材模块。
- 先大纲、后确认、再生成正式分镜的工作流。
- 场景去重、承上/衔接、逻辑检查和独立新 Markdown 文件交付。

## 本版更新

- 将“每个视频编号约30秒”修正为硬规则：默认逐镜时长总和必须恰好等于30秒，29秒、31秒均不得交付。
- 新增 `scripts/check_storyboard_duration.py`，正式交付前自动逐段求和并返回 PASS/FAIL。
- 明确时长不足或超出时只能调整有效镜头、台词拆分或事件边界，禁止用废镜头补秒。
- 时长校验只在内部执行，正式分镜不显示逐镜算式、PASS/FAIL或“时长硬校验”标注。

- 接入用户提供的五维镜头 Skill 原始参考，新增按需调用说明。
- 默认单个视频编号固定30秒；镜头按逻辑灵活分配，通常2—5秒，不固定3秒。
- 默认约8—10镜，但不为凑镜头增加废画面。
- 正式表格改为用户确认的五栏：`镜号｜时长｜景别／机位／运动｜画面与动作｜对白／音效`。
- 删除独立“打光设计”“怪物”“道具／武器”栏；相关信息写入画面与动作，用户单独要求资产参考时再输出。
- 强化台词原文保留，特别是暧昧、笑点、反转和角色口头禅；只压缩废镜头，不压缩逻辑和关键对白。
- 强化人物/丧尸/怪物识别、站位、动作目标、伤势和尾帧连续性；不再使用“阵营锁定”字段。
- 服装不再默认沿用上一段；原文未说明时不额外设计。
- 运镜采用五维 Skill 的“景别—机位—运动—表演—声音—连续性”审查，必要时使用 B-ID/G-ID 内部节拍和生成封装。
- 保留系统界面文字清晰规则，增加模型生成前的五维节拍与反碎片化检查。

新版有效规则优先于历史版本；历史内容可在`历史版本-v1.0/`中追溯。
