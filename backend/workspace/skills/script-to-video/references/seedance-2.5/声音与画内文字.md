# 台词、声音与画内文字

每句写明实际说话人、声音来自哪里及简短表演提示，完整原话只写一次。多人轮流开口就分开归属。同镜有心声时，写出人物当前动作和闭口状态，心声由本人原音画外念出。画外说话人不因此出现在镜头里。

角色有录音时，素材只提供该角色的音色，口播内容取自已确认剧本。对白栏分别写原话和声源明确的拟音，保留用户选择的声音风格。交付格式可用花括号标台词、尖括号标音效。写情绪或重音时避免在台词末尾再摘录原句，降低意外字幕概率。

无对白字幕时，剧情中的圣旨、牌匾、信件和系统面板仍可按剧本显示。具体写明载体、原字、读得清的角度及停留时间。文字需精确还原且已有字样参考图时绑定该图；英文易错词可逐个字母说明。没有字样图时照录原文。台词、音效和屏上文字分别表达。
