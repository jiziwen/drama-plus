# Seedance 2.5 成片问题

只处理用户报告的现象，先检查素材和任务参数，再决定是否调整对应镜头。

| 现象 | 对应处理 |
| --- | --- |
| 角色或声线串位 | 按角色首次出场顺序核对图号、声线、说话者、站位与进出画。 |
| 强情绪时瞳孔发光 | 普通人保持自然眼睛，光线落在面部轮廓，情绪改用具体表情表达。 |
| 画中文字拼错、意外出现字幕 | 精确中文可用字样图，英文可给字母顺序。避免重复引述台词。使用视频参考时检查输入视频已有的字幕。 |
| 特殊 JPG 解码失败、草木出现指纹状花纹 | 解码失败时转标准 JPEG 或 PNG。密纹失真时可用不大于目标视频分辨率的参考图副本，保留原图。 |
| 禁配乐仍出现音乐 | 首尾强调允许的人声与必要物理声，去掉暗示配乐的升调、铺底等文字。后期仅提人声也会去掉拟音。 |
| 听见冒泡、回音、啸叫 | 删除与该镜无关的水波或回音联想；保留原剧情里的真实声源。 |
| 跨版风格漂移、编辑改画幅后内容跑偏 | 延续已有 2.0 素材可用视频延长与 MOV。改画幅可改用参考生成，写清目标构图和逐镜发生的事。 |
| 严格编辑后时长有微差 | 需要严格编辑时可将输入帧数整理为 8n+1；若优先精确成片时长，可用指定时长的参考生成。 |
| 多项视频编辑互相干扰 | 定位失败的单项操作。涉及视频素材时可先完成一项编辑再处理另一项，保留各镜原有时序。 |
| 翻译混语、声线错位 | 按角色核对所有可辨人声、目标语原句和时间轴，逐句对口型。 |
