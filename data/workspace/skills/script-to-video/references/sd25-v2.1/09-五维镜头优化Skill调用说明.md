# 五维镜头优化 Skill 调用说明

本文件是当前智能体与用户提供的 `five-dimension-storyboard v8.2` 原始 Skill 的连接层。原始文件保存在 `五维镜头优化Skill-原始参考/`，只读保留。

## 什么时候调用

处理新剧本、战斗镜头、连续动作、跨编号衔接、复杂场景、巨物/机甲/异象、SD2.5生成封装或用户要求优化景别机位运镜时，按需读取：

1. `SKILL.md`：总流程、优先级、时间模型和交付方式。
2. `references/v8-core-template.md`：导演规划、表演、摄影、声音和连续性基础。
3. `references/platform-profiles/SD25-001_v1.0.md`：SD2.5平台模式与时长能力。
4. `references/platform-profiles/SD25-AUTO-HYBRID_v1.0.md`：需要 STANDARD/LONG/ULTRA 混合封装、连续长动作或生成任务审计时读取。
5. `references/director-modules/`：只有用户明确启用某导演模块时才读取。

不要无关地加载其他平台、导演模块或专项参考。原始 Skill 的平台能力若与当前界面不一致，以当前界面和用户要求为准。

## 调用后怎样转成我们的短剧格式

### P｜项目启动

先锁定项目卡、SD2.5、画幅、总时长、台词是否逐字、BGM/字幕、参考素材和禁用项。默认每个视频编号固定30秒，逐镜算术和必须恰好等于30秒；用户指定其他时长时改为精确等于指定值。

### A｜导演规划

提取本段的事件链、人物目标、空间轴线、视觉风格、情绪变化和结尾钩子。把每一个主要动作拆成一个可审查的导演节拍 `B-ID`，不把一个动作链拆成无意义碎片。

### B｜镜头执行

为每个节拍确定：景别、角度/机位、焦段意图或空间距离、运镜、构图、速度、人物位置、视线、表演、对白、音效和尾帧状态。把台词和动作嵌在一起，优先使用2—5秒的有效镜头。

### G｜生成封装（按需）

连续同场、同主体、同目标的节拍可内部合并为一个 `G-ID`；需要拆分时说明具体原因。使用 `Natural` 表现连续表演，使用 `Timestamp` 锚定必须准时发生的台词、接触、爆炸、转场或身份揭示。不要为了减少任务数量强行合并，也不要为了凑时长碎片化。

### C/D｜模型提示词与平台执行（按需）

生成提示词只保留模型真正需要的画面、动作、声音、连续性和负面限制。上一段尾帧优先级最高；人物身份、伤势、位置、动作方向、物件状态和声音余韵必须继承。内部 B/G/E 标签不必放入用户要看的五列表格。

## 输出映射

用户可见的正式表格固定为：

`镜号｜时长｜景别／机位／运动｜画面与动作｜对白／音效`

五维 Skill 的信息这样落位：

- 景别、角度、机位、焦段意图、运镜、速度 → `景别／机位／运动`。
- 构图、站位、视线、表演、动作因果、物件/武器/丧尸状态、环境反馈、末帧 → `画面与动作`。
- 台词、心声、环境声、拟音、音乐进入点、尾帧声音 → `对白／音效`。
- B-ID/G-ID、MODE、T-GEN、剪辑余量和回退方案 → 只在需要 SD2.5封装/诊断时作为附加审阅信息，不改变五列表格。

## 五维连续性检查

每次生成前后检查：

1. 时间：本镜发生在上一镜之后还是同时？
2. 空间：人物位于左/中/右，前/中/后景和出入口是否连续？
3. 动作：速度、方向、重心、支撑、剩余位移是否接得上？
4. 身份：人类、丧尸、怪物和敌人是否外观与行为可辨？
5. 状态：服装（仅在原文明确时）、伤势、血迹、疲劳、道具/武器和界面是否累计？

## 审计脚本

原始 Skill 的 `scripts/audit_storyboard.py` 只审计含 B-ID/G-ID 的五维封装表。需要审计时，在该目录运行：

```powershell
python .\scripts\audit_storyboard.py .\目标分镜.md
```

它用于检查 B/G 覆盖、SD25 模式时长、LONG 回退和反碎片化风险；它不替代本包的短剧逻辑、台词、人物和五列表格自检。五列表格的精确30秒校验必须另行运行本包根目录下的 `scripts/check_storyboard_duration.py`。

## 冲突处理

用户最新要求和原文台词 > 项目卡 > 本包当前有效规则 > 题材模块 > 五维 Skill 的平台建议 > 原始条例。五维 Skill 负责优化镜头和生成稳定性，不得改变原文背景、人物关系、台词或用户明确禁用项。
