# 一、这套系统模拟什么

本模块不是“让一个模型假装成某位导演”，而是建立一套有真实主创研究锚点、明确部门职责、冲突处理顺序和最终裁决机制的虚拟制作团队。

系统分为三层：

1. 真实人员研究层：记录《环太平洋》（2013）公开片尾中的人员与职位，用来理解实际制作分工。
2. 模板功能映射层：把多人、多部门的方法转化成分镜工作中可执行的职责。
3. AI执行新增层：补充当年剧组不存在、但Seedance工作流必需的物理时间、提示词封装、连续性状态和失败重试岗位。

真实姓名只允许出现在内部规划层、研究说明和主创决策记录中。输出给Seedance的提示词不得出现影片名、导演名、工作人员名、制作公司名或“模仿某人风格”等表述，只能保留原创、可见、可听、可执行的方法结果。

# 四、导演方法锁定

【导演方法锁定｜DIR-PR-001】

## 4.1 核心命题

巨物奇观必须服务人物情绪。每场巨物戏同时回答：

1. 人物正在害怕、选择、承担或失去什么？
2. 巨物动作如何外化人物、组织或世界的冲突？
3. 观众最终记住哪个人物瞬间或力量瞬间？
4. 环境如何证明尺寸、重量、速度和代价？

## 4.2 总导演原则

- 先确定人物视点，再决定巨物景别。
- 先建立空间、目标和攻防方向，再进入冲击。
- 奇观镜头必须提供新信息，不为规模感重复堆镜头。
- 每个不可逆动作都有准备、发生、反作用、环境反馈和结果。
- 高潮后保留损伤、人物反应或环境余波。
- 各部门可以提出替代方案，但每个节拍只保留一个最终裁决。

## 4.3 摄影原则

- 摄影机必须有现实可解释的位置、速度、稳定度和运动能力。
- 以人物、车辆、桥梁、建筑、港口设施、水体和天气建立尺度。
- 巨物可以被前景、建筑、雨幕、烟尘或画框裁切，制造画面装不下的压迫感。
- 动作镜必须保持轴线、攻防方向、接触点和力量去向可读。
- 运镜由人物情绪、主体运动或信息揭示触发，不做无动机炫技。
- 巨物运动中避免长期干净、无遮挡、稳定的全身广角。

## 4.4 表演原则

- 人物不是巨物镜头的比例装饰；驾驶、观察、受击和决策必须有身体代价。
- 台词前后保留呼吸、视线、微表情和听者反应。
- 情绪高潮通过眼神、下颌、手指、肩颈、呼吸和重心呈现。
- 操作者身体反馈与外部受力方向一致，并允许合理传递延迟。
- 巨物也有可读表演：犹豫、试探、愤怒、疼痛、失衡和恢复通过姿态节奏表现。

## 4.5 动作与巨物动画原则

- 机械巨物体现执行器、关节阻力、结构惯性、支撑脚反馈和制动。
- 生物巨物体现肌肉蓄力、身体柔性、动物本能、痛觉和保护反射。
- 不用统一慢动作制造重量；重量来自惯性、阻力、延迟、形变、反作用和恢复。
- 动作按蓄力→加速→接触→力量传播→反作用→环境反馈→恢复规划。
- 攻击者与被击者在接触时同时响应。
- 高速动作后给足制动、滑移、踉跄、撞击或借助环境减速的过程。

## 4.6 美术与巨物设计原则

- 每个巨物必须有原创且远离现有IP辨识特征的剪影。
- 结构与功能互相解释：关节、装甲、器官、武器与运动方式对应。
- 材质必须带有制造、使用、污染、腐蚀、磨损、修补或生长历史。
- 场景同时是比例参照、动作障碍、破坏介质和情绪空间。
- 冷色环境不能只剩纯蓝；以工业暖光、警示色、湿面反射和局部多色光组织层次。
- 设计复杂度不能牺牲轮廓、功能与生成稳定性。

## 4.7 预演与视效原则

- 二维分镜进入执行前，先用虚拟空间验证机位、比例、距离和动作时间。
- 漂亮构图若不符合透视、摄影机可达性或物理距离，必须退回修改。
- 预演是摄影、灯光、美术、动作、特效、布景、剪辑和AI执行的信息中心。
- 环境反馈与主体速度一致，并考虑传播延迟：水体、烟尘、建筑、车辆、碎片不能同帧整齐响应。
- 巨物尺度必须由至少三类可见证据共同建立。

## 4.8 剪辑原则

- 区分T-EDIT、T-PHY、T-SCR、T-BEAT与T-GEN。
- 冲击可以短，准备、压迫、力量传播和余波不能全部压缩。
- T-BEAT通常使用4–15秒完整范围，不把4–5秒当统一默认值。
- T-GEN服从当前平台配置；SD25 LONG可以封装多个连续T-BEAT，但只能服务一个序列目标。
- 巨物动作跨越多个T-BEAT时按物理相位拆分，并继承位置、速度、方向、角速度、支撑和动力。
- 当70%以上T-BEAT集中在4–5秒时，剪辑部门必须重新检查节奏。
- 视点切换必须增加人物代价、空间变化、尺度证据或动作结果。

## 4.9 声音与音乐原则

- 巨物可先通过低频、结构应力、远处水体或建筑反应进入感知，再完整显形。
- 机械声分为动力源、关节、装甲应力、武器与环境接触。
- 生物声包含呼吸、胸腔共鸣、皮肉或甲壳摩擦与痛觉反应。
- 近处接触、远处回声和二次坍塌保留传播时间差。
- 配乐由项目配置卡决定；音乐不得掩盖关键物理声、台词或必要沉默。
- 字幕完全服从项目配置，默认不让生成模型直接制作字幕。

# 六、团队协作流程

## 6.1 标准流程

项目配置PC  
→ 模块适用性检查  
→ 总导演提出场景命题与人物视点  
→ 编剧表演席位锁定剧情因果与表演空间  
→ 制作设计席位建立GMS／SSR／VSC  
→ 物理视效席位建立PHY与T-PHY  
→ 分镜预演席位验证机位、比例、距离与动作时间  
→ 摄影、动作、剪辑、声音提出约束和风险  
→ 连续性席位审查状态继承  
→ 总导演形成唯一DDC  
→ AI执行席位转译并封装Seedance任务  
→ 生成测试  
→ 每日审片式诊断与最小改动重试

## 6.2 部门提交限制

每个席位每个节拍只提交：

1. 最多三个不可妥协项。
2. 一个最可能失败的风险。
3. 一个建议方案。
4. 必要时一个备选方案，但不得自行生成第二套完整分镜。

## 6.3 冲突裁决优先级

1. 用户要求与不可更改项。
2. 台词、人物和剧情因果。
3. 当前有效项目配置PC。
4. 当前平台配置、任务MODE与参考素材限制。
5. T-PHY、动作因果和动态连续性。
6. 人物、空间、比例、伤势、道具与环境连续性。
7. 每个T-BEAT一个主动作及表演可读性。
8. T-GEN封装复杂度与模型可执行性。
9. 总导演的叙事、美术、摄影、剪辑和声音裁决。
10. 致敬、部门偏好与表面风格相似度。

前八项不得被美学、致敬或真实人员偏好覆盖。

## 6.4 预演审查

- 摄影机放进真实或虚拟空间后，机位是否成立？
- 巨物与场景参照是否在同一地面、同一纵深或已完成透视修正？
- 动作距离、速度和时间是否符合PHY计算？
- 水体、建筑、烟尘和碎片反馈是否符合主体速度与传播延迟？
- 二维构图是否会导致空间、比例或生成执行错误？
- 该镜头是否给观众新增信息？
- 能否用更少主体、更少特效和更清楚的动作关系完成？

# 九、失败诊断

| 问题 | 模块修正 |
|---|---|
| 只写真实姓名，没有方法 | 返回对应席位职责，转成可见、可听、可执行裁决 |
| 把复合成果归给一人 | 检查E／F／A标记，恢复多人协作映射 |
| 给AI新增岗位虚构真人 | 删除姓名，标为A并保留功能说明 |
| 直接要求模仿导演风格 | 改写为摄影、表演、动作、材质、剪辑和声音规则 |
| 复制参考影片专有元素 | 重做原创剪影、结构、世界规则、场景和可见转译 |
| 部门意见堆叠 | 总导演形成唯一DDC，删除未采用方案 |
| 节拍全部4–5秒 | 剪辑、物理和表演席位重新分配T-SCR／T-BEAT，并重新判断T-GEN封装模式 |
| 巨物动作过慢失去张力 | 在T-PHY范围内提高动力或改用局部／人物视点，不无理由加速 |
| 巨物动作过快失去重量 | 校准接触形变、环境反馈、制动和恢复，必要时延长T-SCR |
| 构图漂亮但空间不成立 | 返回预演，用虚拟机位、比例和动作距离复核 |
| 驾驶舱与外部受力脱节 | 对齐冲击方向、身体重心、设备反馈与时间延迟 |
| 生成过载 | 减少主体与特效，只保留一个主动作和一个首要环境反馈 |
| 比例漂移 | 重新引用GMS／SSR／VSC，并前置两至三项可见比例关系 |
