# Seedance 2.0 Platform Profile SD20-001 v1.0

> PLATFORM PROFILE ID：SD20-001  
> 适用模型：即梦 Seedance 2.0  
> 定位：五维度分镜 v8.1 的旧项目兼容执行配置  
> 加载别名：Seedance 2.0、即梦 2.0、启用 SD20、使用 SD20  

## 1. Time Contract

- `T-BEAT`：单个导演节拍，4–15 秒。
- `T-GEN`：单次生成素材时长，4–15 秒。
- 在本配置中原则上 `T-BEAT = T-GEN`。
- 每个生成单元只承担一个主动作或一个连续情绪动作，最多两个相邻情绪节拍。
- 每个 Prompt 使用本地时间轴，从 `0s` 开始，到当前 `T-GEN` 结束。
- 短于 4 秒的成片镜头先生成至少 4 秒素材，再在 `T-EDIT` 中标注截取区间。
- 超过 15 秒的剧情、台词或物理动作必须在自然动作相位、情绪转折或台词停顿处拆分，并继承动态尾帧。

## 2. Timing Language

- 默认使用自然演绎模式，不做密集逐秒编舞。
- 用“开场、随后、接触时、峰值后、尾帧”等语义阶段表达动作发展。
- 用户明确要求时间点时可以写少量整数秒锚点，但不得把呼吸、衣物、头发、雨雾等自然运动逐秒锁死。
- 摄影、表演、台词、音效与光线必须服从同一动作因果。

## 3. Reference Budget

按 Seedance 2.0 旧工作流控制参考素材：

- 图片参考：单次最多 9 张。
- 视频参考：最多 3 个，单个约 2–15 秒，总时长不超过约 15 秒。
- 后续镜头优先使用上一段实际尾帧作为起始参考。
- 给每个素材指定唯一控制职责：身份、场景、动作、运镜、音色、比例或连续性；不要让多个参考争夺同一职责。

实际产品界面限制与本配置不一致时，以当前界面为准，并在执行表记录差异。

## 4. Execution Structure

每个生成单元使用：

1. `【模型与任务模式｜SD20-001 / GENERATE】`
2. `【全局风格锁定】`
3. `【场景/节拍锁定】`
4. `【巨物比例锁定】`（触发时）
5. `【参考锚点】`
6. `【上一尾帧与本段连续性锁定】`
7. `【自然生成提示词】`
8. `【台词与声音】`
9. `【负面限制】`

自然生成提示词必须携带景别、角度、焦段或可见空间意图、机位、运镜、构图和速度。

## 5. Validation

- [ ] 当前 `PC ID` 已锁定 `SD20-001`。
- [ ] 所有 `T-GEN` 为 4–15 秒。
- [ ] 每段本地时间码从 `0s` 开始。
- [ ] 超长内容已拆分并继承尾帧。
- [ ] 未误用 Seedance 2.5 的 30 秒、180 秒、白模或高级编辑能力。
- [ ] 参考素材数量与总时长未超出旧配置。
