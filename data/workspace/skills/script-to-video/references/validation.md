# 校验与来源

Skill 在写完或改完正式分镜、提示词候选时自动完成以下检查。先用当前草稿执行时长检查，包含五维封装或声明 AUTO-HYBRID 时也执行封装审计，并另行核对原文和实际配图。修复失败的格式、错配的时长声明或可确认的绑定错误后复验；保留原台词、剧情和真实动作时长，不能删除关键镜头或填充空镜来通过校验。分批生成时每批最多自动修复三次，整集单次生成时整集共用三次。每轮修正本地校验指出的问题。达到上限后保留草稿，向用户显示剩余问题。需要用户消歧时只说明具体段落、人物造型或剧情缺项。程序错误保留内部诊断，正式稿省略算式、PASS/FAIL 和诊断记录。

在候选采用、提交生成和导出时，用实际将被采用或交付的内容自动复验。手工编辑过程中允许暂存草稿。这些检查由调用方执行，不需要用户点击单独的检验按钮。Agent 能调用命令行时，从项目根目录使用后端已安装的 tsx：

```sh
backend/node_modules/.bin/tsx backend/workspace/skills/script-to-video/scripts/check-storyboard-duration.ts 分镜.md
backend/node_modules/.bin/tsx backend/workspace/skills/script-to-video/scripts/audit-storyboard.ts 五维封装.md
```

均支持多个 Markdown 路径和 `--json`。时长工具默认每卡取标题或“总时长”声明，验证每镜正秒数、精确合计、30 秒上限；可加 `--target 12` 检查所有卡均为指定秒数。时长不合格退出 1，文件/用法错误退出 2。五维工具验证 B/G 覆盖、模式、合并理由、回退和时间控制；警告退出 1，错误退出 2，通过退出 0。普通五列分镜可以单独检查时长。文档明确声明 SD25-001 / AUTO-HYBRID 时，还须提供实际的 G-ID 封装表。审计会跳过模板占位行与配图清单。项目版加强了引用完整性：已填主封装表须配套 B-ID 导演节拍表，覆盖不存在的节拍按错误报告，LONG 须依序覆盖连续节拍且不跨硬边界。浏览器直接调用 `validateStoryboard(markdown)` 组合两种检查，错误位置为 Markdown 的 1 基行号。

完整 SD2.5 v2.1 来源保存在 [sd25-v2.1](sd25-v2.1/SKILL.md)，所有规则、模板、题材、自检、五维核心、平台配置、导演资料和原检验源码逐文件原样保留。两个 TypeScript 命令分别改编自其中 `scripts/check_storyboard_duration.py` 与 `五维镜头优化Skill-原始参考/scripts/audit_storyboard.py`；Python 源码和原测试仅供追溯与回归，不是本项目运行入口。原包中所有“运行 Python”或 PowerShell 审计指令均映射到上面的 tsx 命令，仍使用相应时长检查或封装审计，不执行归档 Python。

网页生成与交付另外使用 `backend/src/services/script-video-types.ts` 的正式稿检查：制作规格、人物声音锁定、每段承上／场景／人物／独立生成／衔接不可缺失；原对白与说话人、配图引用和提示词同步状态也要核对。缺字段的旧稿可保留编辑，不能当成完整正式稿交付。达到单次输出上限的模型结果立即停止，不把截断内容保存为正式版。

生成正式分镜时，模型按本次请求指定的范围提交 cards，逐段对照原文核对首末镜承接。程序验证这些片段的顺序、精确时长、完整模板和实际配图。续写从已保存的末镜接起。所有片段齐备后再用整集原文核对对白、说话人和顺序，通过后发布正式稿。整集 AI 语义复核由用户单独发起。

新大纲优先把主干剧情排入120秒以内。人声在精简画面、跨段分配后仍需额外时间时，由模型自行延长，具体取舍见[项目适配说明](../项目适配说明.md)。整集按本次实际分段校验，非尾段精确30秒，尾段大于0秒且不超过30秒。每段逐镜秒数必须合计为该段时长，跨段台词须逐字衔接、在整集内按原顺序出现一次。既有正式稿按各自版本的时码核对。命令行通用时长工具按各段声明值检查。

高燃打斗使用整体移动后的 [fight-choreography](../fight-choreography/SKILL.md)，保留完整原文章节，已按用户要求移除 Word 原件，不再读取原 `script-rewriter` 位置或概括版打斗说明。
