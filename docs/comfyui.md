# ComfyUI 本地生成

火宝通过 ComfyUI 原生 HTTP API 提交 API 格式工作流；生成任务仍进入 `sys_task`，完成后下载到 `data/static`，回写角色、场景、道具或分镜。ComfyUI 独立运行，不打包进 Electron。

## 当前机器

- 整合包：`D:\comfyui\Comfyui-WF-2026.8.8`
- ComfyUI：`http://127.0.0.1:8188`
- Docker 内的火宝访问地址：`http://host.docker.internal:8188`
- 火宝：`http://localhost:5679`

重启电脑后可双击桌面的「火宝短剧」快捷方式，同时启动 Docker 应用和本地 ComfyUI。也可以手动运行 `powershell -ExecutionPolicy Bypass -File scripts/start-comfyui.ps1` 后执行 `docker compose up -d app`。

本机运行镜像为 `huobao/huobao-drama:comfyui-local`，由本地 compose override 选择，已排除 Watchtower 自动替换。原镜像备份标签为 `huobao/huobao-drama:before-comfyui-20261028`。数据目录仍挂载仓库的 `data/`，接入前有 SQLite 在线备份 `data/huobao.sqlite3.bak-before-comfyui-20261028`。

## 设置与使用

设置 → AI 服务 → 添加图片或视频配置 → 选择 **ComfyUI · Work-Fisher** 预设，填写后端可访问的 Base URL。未启用鉴权的本地 ComfyUI 不需要 API Key；反向代理启用 Bearer 鉴权时可填写 Key。

| 模型 ID | 用途 |
| --- | --- |
| `wf-image` | 自动选择：角色→角色模式，场景→场景模式，有显式参考图→三视图模式 |
| `wf-z-image` | 原「角色资产生成编辑」，含 SeedVR2 和原始后处理 |
| `wf-z-scene` | 原「场景资产生成编辑」，独立模型和采样节点 |
| `wf-qwen-image` | 原「三视图生成编辑」，需参考图，保留潜空间切换 |
| `wf-minimax-h3` | 原「多参生视频编辑」，最多 6 张参考图，包含生成音频 |

在集工作台顶部的图片、视频选择器中选择对应 ComfyUI 模型，之后使用原有生成按钮。已有集锁定的原服务仍然有效，可在顶部显式切换。默认配置由设置页的星标／优先级决定。

连接测试只读取系统和节点信息，并检查预设所需模型、LoRA 是否安装，不提交生成任务。实际生成失败时，任务错误中会显示 ComfyUI 节点错误。

## Work-Fisher 工作流来源

2026-10-29 已替换原先的手写简化预设。运行时直接读取用户指定的 `【Work-Fisher】AI短剧制作全流程.json` 的原样副本 `backend/src/services/work-fisher/source.json`。该副本与本机原文件的 SHA-256 一致；`work-fisher.ts` 根据原分组、节点输入和连线转换为 API 格式，不再手写模型或采样节点。完整核验见 [节点核验记录](work-fisher-node-audit.md)。

- 角色：解码 `236` 后保留原图保存与预览，以及 `234 → 231 (SeedVR2) → 280 → 281 → 239`。最终读取 `239`，不取原图 `241`。SeedVR2 的 7B Q8 模型、分块设置、0.3MP 预缩放和连接到 `237` 的 2560 短边目标均保留。
- 场景：完整保留独立的 `253–277` 场景节点与 `282/283` 清理链，最终读取 `267`。
- 三视图：保留 `207` 潜空间开关及两侧输入、`213` 尺寸选择器、`206` 参考图编码分辨率 1024、`284/285` 清理链，最终读取 `212`。可使用画布上的 4 个参考图插槽。
- 多参视频：保留原尺寸选择器、帧数表达式、12 步输入常量、LoRA、attention、`286/287` 清理链和原 H.265 10-bit、CRF 22、元数据保存配置，最终读取 `156`。不再擅自替换成 H.264。

只省略便签和画布分组开关等前端节点；Reroute 按原连线解析为同一上游，不省略执行分支。RAM/VRAM 清理是执行节点，全部保留。每次只激活所选原始模式；提示词、种子、时长、显式尺寸和参考素材作为输入注入。参考图替换原 LoadImage 输入，不运行画布中的旧示例素材。自动图片在无参考图时按资产类型选择角色或场景模式，有参考图时选择三视图模式。

在工作台明确选择「三视图生成编辑」并对角色点击生成时，优先使用该角色保存的参考图，其次使用当前形象图；没有参考图时提示先生成或上传角色形象，不会运行原文件的 example.png。自动角色模式不会因为已有图片而擅自切换到三视图。

提交中携带 `extra_data.extra_pnginfo.workflow` 原始画布（同步激活模式及本次输入）与来源哈希。生成 PNG 可拖回 ComfyUI 检查执行画布；不会自动向 ComfyUI 的已保存工作流列表添加文件，也不会修改整合包中的原文件。

默认不再添加约 1MP / 0.2MP 的人为上限。未传尺寸时，角色原始输入为 1024×1680（随后 SeedVR 放大），场景 1920×1080，三视图原选择器为 2MP、16:9（1920×1088），视频原选择器为 0.6MP（16:9 时 1056×608）。显式任务尺寸或已保存的服务尺寸仍作为用户输入生效。**设置 → AI 服务 → 编辑对应的 ComfyUI 图片／视频服务 → 生成分辨率** 可修改；切回默认使用原流程。原文件本身的高分辨率和 SeedVR 会增加显存及耗时。

宽高保存在 `comfyui.width / height`。角色和场景改原有尺寸常量；三视图通过原选择器的比例及像素面积接收尺寸，仅支持原选择器的比例；视频使用两者乘积控制清晰度，并跟随项目比例换算宽高。例如基准 `832×480` 配合项目 `9:16`，实际提交 `480×832`。角色最终文件尺寸由原 SeedVR 节点决定，任务中记录的是基础生成尺寸。自定义 API 工作流继续支持 `{{width}}`、`{{height}}`。原任务恢复仍读取持久化的输出节点（包括旧 `241`），不改动既有任务。最长等待默认 120 分钟，包含排队。

当前视频预设接收参考图片；视频、音频素材输入及首尾帧约束模式尚未接入，会明确报错。图片上传保留原素材，不走云服务压缩和公网 URL 转换。素材会保存在 ComfyUI 的 `input/huobao`，生成结果在 ComfyUI 的 `output/Huobao` 和火宝数据目录各有一份。

## 自定义 API 工作流

高级面板支持导入 ComfyUI **Export (API)** JSON，并编辑配置：

```json
{
  "workflow": {
    "6": { "class_type": "CLIPTextEncode", "inputs": { "text": "{{prompt}}", "clip": ["4", 1] } }
  },
  "outputNode": "9",
  "maxPixels": 1048576,
  "fps": 24,
  "frameStep": 17,
  "frameOffset": 5
}
```

上面只展示参数结构，实际 `workflow` 必须含完整可运行节点及存在的输出节点 `9`。字符串占位符支持 `prompt / width / height / seed / frames / fps / duration`；整个字段是数字占位符时会保留数字类型。导入后需要将固定提示词等输入换成占位符。

对于支持动态多图输入的节点，可设置 `referenceNode`、`referencePrefix`、`referenceStart`、`maxReferences`。火宝上传素材并创建 LoadImage 节点，再连接这些动态输入。例如 Qwen Image 使用 `referenceNode: "206"`、`referencePrefix: "images.image_"`、`referenceStart: 1`。普通固定 LoadImage 输入的自定义工作流需要按其节点输入结构调整，目前导入功能不会自动推断映射。

任务会在提交前持久化客户端生成的 `prompt_id`；中断后图片任务可自动继续查询，视频可以恢复原任务。配置删除、停用或地址变更后，不会自动切换到其他 ComfyUI 实例恢复。ComfyUI 自身历史被清空时无法恢复输出定位。

## 中文提示词

图片最终提示词、视频提示词及分镜 Agent 新创作的画面、动作和运镜描述以简体中文为主，不跟随界面语言切换。已有系统提示词、视觉风格词（如 `high-quality`）、模型名、资产名称和技术术语可保留英文，不因混入这些词拦截。项目配置中的风格描述直接原样拼接，不做翻译和中文校验。视频提示词 Agent 的工具仅接受分镜 ID 和 `video_prompt`，无法覆盖场景绑定、时长或其他字段。

已有图片最终提示词在下次使用时保留匹配项目配置的系统风格前缀，只对需要转换的英文创作正文使用已配置的文本模型翻译。翻译会产生文本模型调用，记录中可查看。原有英文视频提示词可以点击「重新生成」换成中文，手动输入内容不批量改写。

## 接口调用记录

设置 → **接口调用记录**，或者集工作台右上角「接口记录」。可按服务商、状态、任务编号和接口路径筛选；「查看详情」弹框并列显示请求头、请求体、响应头、响应体、错误、耗时及生成任务编号。

记录保存在 SQLite 的 `api_call_logs`，从功能启用后开始记录，最多保存最近 5000 条。覆盖文本模型实际 HTTP 请求、图片／视频生成、查询、交付下载，以及 ComfyUI 工作流提交、参考图上传、历史查询和下载。流式文本响应按 SSE 事件记录；文件和 Base64 仅显示元信息。鉴权字段、Cookie、URL 签名已隐藏，单条详情上限 1MB，超出会标记截断。

相同请求默认合并展示，保留每次实际调用。合并依据包含任务、服务商、方法、完整地址、请求头和入参；响应不同不会拆组。列表显示调用次数、首次／最近时间、各状态次数和最新响应，可关闭「合并相同请求」查看原始列表；详情内可查看最近 50 次单独响应。旧记录启动时会补充合并键。

GET 查询没有请求体。详情会展开 URL 中的路径参数（例如 ComfyUI `prompt_id`）和查询参数；ComfyUI 进度查询还会关联同任务的 `POST /prompt`，点击「查看生成入参和响应」可查看真正提交的工作流。历史单次响应（包括空对象）保持原样，合并列表默认展示最新一次响应。

## 打开火宝时联动启动整合包

设置 → 通用 → **本地 ComfyUI 联动启动**，可开关自动启动、查看状态和手动发起启动。

Docker 无法直接创建 Windows 进程，因此 Windows 上的 `scripts/local-runtime-host.ps1` 负责接收 `data/local-runtime/` 中的固定启动请求，调用指定整合包的 Python 和 `main.py`。不接受网页传入任意命令。已有服务会复用；重复打开页面会合并启动请求。ComfyUI 在后台运行，不自动打开整合包启动器窗口。

如果打开后立刻生成，本地生成任务会等待整合包就绪再提交工作流，最长等待 5 分钟；远程 ComfyUI 不受本机启动逻辑影响。

本机已通过 `scripts/install-local-runtime.ps1` 安装桌面快捷方式「火宝短剧」和 Windows 登录启动项「Huobao Local Runtime」。登录时仅启动轻量助手，ComfyUI 在打开火宝后按需启动。直接打开已有火宝网页也会触发联动。助手状态由本地文件心跳提供；若助手离线，使用桌面快捷方式即可启动助手。

更换整合包位置后执行 `powershell -ExecutionPolicy Bypass -File scripts/install-local-runtime.ps1 -PackagePath "新路径"` 并重启本机助手。关闭联动开关不会停止已经运行的 ComfyUI。卸载助手可删除 Windows 启动文件夹中的 `Huobao Local Runtime.lnk` 和桌面快捷方式，再结束对应 `local-runtime-host.ps1` 进程。
