# 小李短剧：新版与旧版

新版视觉采用由黑蓝向底部亮蓝过渡的星空渐变，正文使用高对比白色，面板和按钮使用同色系蓝色柔光阴影。镜头工作间在桌面与窄屏都居中，保持四周留白及内部滚动。色调集中维护在 `cinematic-lighting.css`，不影响旧版主题。

直接访问应用首页或项目地址即可使用正式界面。首次使用默认新版；右上角“旧版 / 新版”切换并记住本机选择，项目路径、其他查询参数和锚点保持不变。

正式地址参数为 `interface=cinematic` 或 `interface=classic`。历史 `preview=cinematic/classic` 链接自动迁移，`/preview/studio` 仍可跳转到正式首页。本机偏好键继续使用 `xiaoli:interface-mode`，已有选择不会丢失。

## 共用真实业务

两版挂载同一套业务页面：项目与分集、原文与 AI 改写、角色/场景/道具、分镜、图像与视频任务、历史产物、拼接成片，以及完整设置、模型、Prompt/Skills、调用日志、存储和桌面运行时。所有保存与生成继续使用现有 `/api/v1`、`useApi` 和 `useAgent`，不存在新版专用的样例数据库。

新版首页只使用后台返回的项目。没有项目时展示创建入口；没有封面时使用明确的中性占位图。原来的虚构故事与影院示例不再混入正式业务界面。新影院只读当前分集真实视频、绑定的视觉素材或已完成成片，无素材时显示待制作；原播放器、生成、恢复、拼接和下载入口继续保留。

首页素材按每个项目的场景图、角色图依次展开，排除道具，按图片文件路径去重（同文件的缓存参数不产生额外卡片）。正式画廊为有限滑动，每张素材只渲染一张卡片，首尾停止。项目书架的默认封面也优先采用场景图，再采用角色图。

## 资源与交付

正式动效放在 `frontend/app/public/studio/`：星空、流动影像、影院及本地字体和 Three.js。模块之间使用本目录相对路径，运行时不依赖历史预览目录，也不请求第三方 CDN。字体和 Three.js 许可随 `studio/vendor/` 一起提供。占位图为本项目编写的 SVG，不是生成结果。

`npm run generate` 将上述资源放入 `.output/public/studio/`；桌面现有打包流程整体复制 `.output/public`，可使用相同资源。三套早期静态概念预览及示例素材已移除；正式运行资源仅维护本目录，旧版业务界面仍可切换。

## 验证边界

前端测试与静态生成已通过，并核对了产物内的正式模块、CSS、字体和占位资源。测试覆盖默认新版、持久选择、存储不可用、旧链接迁移、真实项目选择、空媒体、真实影院快照与设置读取。内置浏览器另验证正式路由及版本切换。

AI 真实生成和 FFmpeg 成片需要用户内容及可用的原有生成服务；本轮没有提交计费生成、覆盖用户剧本或删除真实项目。界面接通不代表上游服务已经完成生成验收。
